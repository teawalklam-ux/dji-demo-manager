# SOP 图片隐私审核

公开发行版采用文字步骤，不内置来自业务系统的截图。管理员在自己的受控部署中仍可配置截图；上传前应审核姓名、联系方式、客户关系、地址、编号、部门和公司标识。

不得把旧生产截图或旧合成截图直接放回 public/sop-steps；截图中的侧栏与浏览器内容也需要审查。重新制作素材时只使用完全虚构的培训数据和通用品牌。

公开图片必须经过人工审核，并在 docs/reviewed-public-images.json 中记录相对路径与 SHA-256。自动检查只验证内容与已审核版本一致，不代替人工隐私审查。图片发生变化后必须重新审核。

scripts/capture-sop-screenshots.mjs 是本地采集辅助工具，其输出不自动获得公开授权。请同时核对其配套验证脚本与本次文字指引模式的差异。
